# 把内容渲染成图片。

为 Entari 提供简洁可靠的图片渲染能力：支持 HTML、Markdown、纯文本与 Jinja2 模板，也内置 Pillow 与 Skia Python 绘图。

[快速开始 →](<https://entanex.github.io/entari-plugin-htmlrender/0.2.0/start/quickstart/index.md>) [使用指南](<https://entanex.github.io/entari-plugin-htmlrender/0.2.0/guides/rendering/index.md>) [配置参考](<https://entanex.github.io/entari-plugin-htmlrender/0.2.0/configuration/overview/index.md>)

- **多种输入** HTML · Markdown · 纯文本 · Jinja2
- **原生引擎** Takumi 零浏览器 · Playwright 按需扩展
- **独立绘图** Pillow · Skia Python 绘图与热重载
