# v0.7.2 迁移说明

v0.7.2 开始把分散设置合并为结构化配置，并为路径、远程资源、缓存与并发增加显式预算。继续升级到当前版本时，不要保留扁平环境键；以[配置总览](../../configuration/index.md) 的 `RenderSettings` 为唯一来源。

重点复核：

- 本地路径只允许 `resources.local_access.allowed_paths` 下的内容；
- 远程资源默认拒绝私网，并受 redirect、timeout 与并发限制；
- template/resource cache 都有容量上限；
- Provider 专属设置只放在 `provider_config`；
- 迁移完成后运行真实 Provider probe、资源拒绝测试与 cleanup/drain 测试。
