# v0.8 迁移指南

v0.8 把渲染接口收口为 typed request/artifact/error，并把 HTML Provider 与独立Graphics capability 分开。现行 Entari 宿主迁移请直接阅读[专门迁移页](nonebot-to-entari.md)，不要从本页复制旧宿主配置。

## 调用面

- 常用路径使用 `render_html`、`render_text`、`render_markdown`、`render_template`、`render_template_html` 与 `rasterize_html`。
- HTML 解析使用同步 `parse_html`；资源 URL 解析使用异步 `resolve_resource_url`。
- `RenderedImage` / `RenderedHtml` 是结果边界；底层异常被收束为稳定的`RenderingError` 子类。

## 资源与缓存

本地路径与远程网络访问使用统一授权模型。`ResourceResolution` 同时携带解析值与精确 URL 请求头，调用方不得把授权扩张到 host/prefix。Resource Reader、Jinja、filehost 与 native cache 都由一次 runtime 生命周期拥有。

## Provider SDK

第三方 Provider 实现 `EngineProvider`，通过 entry point 发现；composition 注入`ProviderDependencies`。Pillow/Skia 只实现 `RasterSceneRenderer`，不是 HTML
Provider。
